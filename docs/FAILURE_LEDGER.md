# Failure Ledger

任何接入真实系统后的故障都应记录在此账本，并在确认修复后增加回归 Eval。

| 日期 | 现象 | 触发条件 | Root Cause | 所属层 | 修复方案 | 加入 Regression Eval |
| --- | --- | --- | --- | --- | --- | --- |
| 待记录 |  |  |  | AUTH / STATE / ROUTING / TOOL / JAVA_API / RAG / LLM / TERMINATION / PERSISTENCE / OBSERVABILITY |  | 是/否 |

不得把凭证、完整认证头、密码或无关用户敏感数据写入账本。
